Currently building **[RouteCast](https://github.com/JustSid26/route-cast)** — a capacity-aware vehicle routing platform: upload delivery stops and a fleet, get optimized routes back on a map.

## Selected work

- **[study-desk](https://github.com/JustSid26/study-desk)** — Local-first study tracker. Notes are real files on disk, LeetCode problems open and submit inside the app, and a Java/Python scratchpad runs on a button. *TypeScript, SQLite*
- **[data-bench](https://github.com/JustSid26/data-bench)** — Drop in a dataset; it profiles every column, works out which ML problem the data actually poses, trains the models that fit, and explains the result in plain language. *Python, FastAPI*
- **[watched](https://github.com/JustSid26/watched)** — Native iOS tracker for films and TV: watchlists, release reminders, a stats dashboard, and an on-device recommendation engine. *SwiftUI, SwiftData, TMDb*
- **[mock-interview-ai](https://github.com/JustSid26/mock-interview-ai)** — Multi-agent interview coach. Interviewer, Evaluator and Coach agents collaborate through a rule-based orchestrator instead of one monolithic prompt. *Python, Groq*
- **[openData-gov](https://github.com/JustSid26/openData-gov)** — Analytics over 41,000+ records of India's open government data — foodstock, rainfall and air quality — with MapReduce jobs feeding interactive dashboards. *Hadoop, HBase, Flask*
- **[SmartContract](https://github.com/JustSid26/SmartContract)** — Rule-based validation layer for on-chain agreement logic, checking invariants before contracts execute. *TypeScript*
- **[HiggsBosonDetectionML](https://github.com/JustSid26/HiggsBosonDetectionML)** — Classifiers separating Higgs boson signal events from background noise in CERN ATLAS open data, from notebook to deployed model. *scikit-learn, Jupyter*
- **[mushak](https://github.com/JustSid26/mushak)** — Rover firmware for a NASA rover project: wireless controller-to-rover link, motor driver control, and encoded-path visualization. *ESP32, Arduino, Python*
